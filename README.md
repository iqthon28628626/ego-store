# EGO STORE — نسخة بداية

## الملفات
- `index.html`: واجهة متجر بسيطة، صفحة منتجات جاهزة، صفحة طلب تصميم مخصص، وتسجيل دخول ولوحة إدارة أولية للمنتجات.
- `supabase.sql`: جداول قاعدة البيانات وسياسات الوصول.
- `SETUP-AR.md`: خطوات الإعداد.

## تنبيه مهم
هذه نسخة بداية تجريبية وليست جاهزة لاستقبال مدفوعات حقيقية أو إطلاق تجاري دون اختبارات ومراجعة أمنية. طلبات واتساب لا تحفظ تلقائياً في جدول orders. رفع صورة التصميم المخصص غير مفعّل في هذه النسخة؛ يتم ذكر اسم الملف فقط في رسالة واتساب. لا تضع Secret key أو service_role key داخل ملفات الموقع.
